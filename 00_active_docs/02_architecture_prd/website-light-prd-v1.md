# SADHANA 官网轻量 PRD v1

## 1. 文档目的

本 PRD 用于定义 SADHANA 首版英文 B2B 官网的目标、范围、页面要求、功能边界与验收标准。  
该文档用于指导后续：
- 页面原型
- Figma 结构设计
- 文案撰写
- WordPress 搭建

当前版本为 `轻量 PRD`，重点用于快速推进首版官网落地，不追求一次性覆盖所有后续运营需求。

---

## 2. 项目背景

SADHANA 当前已有官网、阿里国际站、产品目录和较多产品图素材，但现有公开口径仍偏泛，不足以清晰表达公司在 `酒店化妆镜、工程配套、定制能力` 方面的真实优势。

根据创始人与一线业务访谈，公司的核心竞争力不在“标品铺货”，而在：
- 五金结构与工艺落地能力
- OEM / ODM 定制能力
- 酒店工程与卫浴空间项目适配能力
- 高品质材质与表面处理控制

因此新官网的目标不是做成目录站，而是做成 `聚焦酒店化妆镜和工程定制能力的 B2B 获客官网`。

---

## 3. 项目目标

## 3.1 业务目标
- 获取更精准的酒店工程和定制类询盘
- 建立真实工厂与专业能力信任
- 支持销售更高效地解释产品、场景、定制和合作方式

## 3.2 用户目标
- 快速知道 SADHANA 是谁
- 快速理解公司最擅长什么
- 快速判断是否适合自己的项目
- 快速进入询盘沟通

## 3.3 网站目标
- 让首页完成定位、产品入口、信任建立和转化引导
- 让产品页具备基础参数、图片、定制和询盘能力
- 让 Customization / Projects 页面承接工程与定制客户

## 6. 核心定位与价值主张

## 6.1 公司定位
`专注酒店卫浴空间与化妆台面场景的金属化妆镜定制与工程配套工厂`

## 6.3 网站需持续强调的 3 个核心卖点
1. 五金结构与工艺落地能力
2. 高品质材质与表面处理控制
3. OEM / ODM 定制与工程项目支持

## 15. 验收标准

## 15.1 结构验收

- 页面逻辑清晰
- CTA 分布明确

## 15.2 内容验收
- 英文表达清晰
- 产品参数完整度达到首版标准
- 公司定位与卖点表达统一

## 15.3 功能验收
- 表单可提交
- 邮件可接收
- 下载可用
- 页面跳转正常
- 手机端可正常浏览

## 15.4 转化验收
- 首页有明确转化入口
- 产品页有询盘入口
- 联系页可收集完整询盘信息
