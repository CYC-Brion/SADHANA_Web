# Product Data Guideline v1

## 1. Why Product Data Matters

For B2B hotel and engineering buyers, product pages are not posters. They are procurement documents.

Each product page should help the buyer answer:

- What is this product?
- Is it suitable for my project?
- What specifications can I evaluate?
- What can be customized?
- Can I forward this to my team?
- How do I start an inquiry?

## 2. Required Product Fields

| Field | Required | Notes |
|---|---:|---|
| Product ID | Yes | Internal website ID, e.g. `WM-LED-001` |
| Category | Yes | Match website category |
| Product Name | Yes | English product name |
| Model | Yes | If available |
| Size | Yes | Diameter / width / height / arm length |
| Material | Yes | Brass, stainless steel, iron, glass, etc. |
| Finish / Color | Yes | Chrome, brushed nickel, matte black, gold, brass tone, rose gold, custom |
| Lighting | If LED | LED type, touch, sensor, dimming, etc. |
| Color Temperature | If LED | Warm / neutral / cool, exact K if known |
| Magnification | Yes | 1x, 3x, 5x, 7x, 10x, etc. |
| Installation | Yes | Wall mounted, tabletop, handheld |
| Custom Options | Yes | Size, finish, logo, packaging, lighting, structure |
| MOQ | Recommended | Can be range if exact number is sensitive |
| Lead Time | Recommended | Sample and mass production if available |
| Application Scenarios | Yes | Hotel bathroom, vanity area, guest room, project |
| Image Folder | Yes | Source folder path |
| Spec PDF | Later | Link when available |

## 4. Color / Finish Data Standard

Use consistent English naming:

- Chrome
- Brushed Nickel
- Matte Black
- Gold
- Brass Tone
- Rose Gold
- Antique Bronze
- Custom Color

Avoid inconsistent names such as:

- golden
- black color
- white chrome
- champagne if it actually means brass tone

If the Chinese source folder uses a local name, map it to a standardized English finish.

## 5. Product Page Structure

Recommended product detail page modules:

1. Product gallery
2. Product name and short value statement
3. Key specification table
4. Color / finish options
5. Custom options
6. Application scenarios
7. Download / spec sheet
8. Simple inquiry form
9. Related products

## 6. Data Completion Workflow

1. Select product folder.
2. Choose 3-6 website-ready images.
3. Fill the product data row.
4. Write one buyer-facing value sentence.
5. Mark missing specs.
6. Ask founder / salesperson to confirm missing data.
7. Create product detail content.
