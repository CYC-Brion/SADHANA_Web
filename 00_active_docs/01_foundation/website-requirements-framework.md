# SADHANA 官网内容基础 v1

## 1. 项目定义

### 1.1 网站类型
- WordPress 英文版 B2B 外贸官网
- 不做电商购物、在线支付、会员、评论
- 以 `品牌信任建立 + 精准询盘转化` 为核心目标

### 1.2 当前项目目标
- 建立清晰的公司定位
- 展示核心产品与定制能力
- 展示工程案例与信任证明
- 获取更精准的酒店工程和定制询盘

### 1.3 当前阶段结论
- 首版网站不是做“全产品目录站”
- 首版网站也不是做“品牌展示册”
- 首版网站要做成：`聚焦酒店化妆镜、强调定制与工程配套能力的获客官网`

## 2. 公司定位

### 2.1 中文定位
SADHANA 更适合被定义为：

`专注酒店卫浴空间与化妆台面场景的金属化妆镜定制与工程配套工厂`

### 2.2 英文定位建议
- `Custom Hotel Makeup Mirror Manufacturer`
- `Hospitality Makeup Mirror Factory with OEM/ODM Support`
- `Custom Hospitality Mirror Supplier for Hotel Projects`

### 2.3 为什么这样定位
根据创始人和一线业务访谈，公司的真实优势不是普通标品铺货，而是：
- 五金结构与工艺沉淀深
- 能把设计师和项目方的想法做成可量产产品
- 能在品质、工艺和成本之间找到平衡
- 对酒店工程和个性化定制项目配合能力强

### 2.4 网站必须传达的三句话
- 我们是一家专注酒店卫浴空间与化妆台面场景的金属化妆镜工厂
- 我们能够把设计师和项目方的想法转化为可量产、可交付的产品
- 我们具备五金结构、表面处理、定制打样和工程配套能力

## 3. 公司优势

### 3.1 已确认的核心优势
- 五金结构与工艺落地能力强
- 能根据设计要求与应用场景优化产品方案
- 在品质、工艺与成本之间找到平衡

## 4. 目标客户

### 4.1 优先客户
1. 酒店工程承包商
2. 海外酒店业主
3. 软装设计公司
4. 品牌定制客户
5. 有相关采购经验的外贸采购商

### 4.2 非目标客户
- 零售终端消费者
- 小批量个人买家
- 低价塑料镜 / 小商品型采购客户
- 追求在线下单的客户

### 4.3 有效询盘定义
一个更理想的有效询盘应具备以下特征：
- 有明确产品需求
- 场景清楚，最好与酒店 / 卫浴空间 / 化妆台面相关
- 能进入具体参数、材质、结构、颜色、交期沟通
- 不是单纯随便问价
- 最好有类似卫浴、镜类、工程类采购经验

## 5. 产品定位

### 5.1 首版官网主推产品
- LED Wall Mounted Makeup Mirrors
- Folding Wall Mounted Mirrors
- LED Tabletop Makeup Mirrors
- Selected Non-Lit Tabletop Mirrors
- Hotel Custom Mirrors

### 5.2 首版弱化产品
- Handheld Mirrors
- 灯具类
- 低价通货型产品

### 5.3 为什么这样取舍
- 壁挂镜，尤其是折叠壁挂镜 / LED 壁挂镜，是当前最重要的业务产品线
- 折叠式 LED 壁挂镜是最容易带来询盘的品类
- 个性化设计师款壁挂镜、工艺要求高的酒店挂镜最能代表工厂能力
- 台式镜是重要补充，但首版更适合精选展示

### 5.4 当前已确认的图片资产基础
本地 `pics` 文件夹主要已有：
- LED 台式镜
- LED 壁挂镜
- 非带灯台式镜
- 非带灯壁挂镜
- 手柄镜 / 手持镜

当前判断：
- 小型化妆镜产品是最容易快速成站的内容基础
- 大型工程镜如果单品素材不足，应先通过案例页、定制页、目录页来承接

## 6. 客户为什么会选择我们

### 6.1 已验证的成交原因
- 真正的生产工厂
- 有解决结构和工艺问题的能力
- 细节、材质、表面处理更专业
- 能做个性化、工程型、定制型产品
- 能在品质和价格之间提供更合理的平衡
- 售前售中售后更靠谱

### 6.2 客户最认可的点
- 结构
- 材质
- 表面处理
- 耐用性
- 定制色能力
- 出口安规和认证意识

### 6.3 客户最常关心的问题
- 是否支持非标定制
- 是否有酒店工程经验
- 质量是否稳定
- 交期是否可靠
- 是否懂出口认证和安规
- 是否能根据应用场景给出更优方案

---

## 7. 客户为什么会放弃我们

### 7.1 已确认的流失原因
- 价格不匹配，尤其是客户想用标品价格做定制
- 旧供应商主动降价，客户不愿切换
- 客户自身未拿到项目
- 定制款交期太紧
- 运费与空运成本过高

### 7.2 这对网站的启发
- 网站不要主打“便宜”
- 网站要主打“价值”“定制能力”“项目适配度”“信任感”
- 网站要帮助客户理解为什么你们价格更高但更值得

## 8. 现有可讲案例方向

### 8.1 日本客户案例
- 客户 SOP 严格
- 前期有磨合
- 公司整改速度快
- 第三轮后基本稳定达标

适合强调：
- 快速反应
- 高执行力
- 严格配合客户标准

### 8.2 德国客户案例
- 设计方案若直接开模，成本过高
- 公司通过五金工艺方案替代高成本模具方案
- 帮客户实现个性化效果，同时控制成本

适合强调：
- 工艺结构解决方案
- 成本与设计平衡能力

### 8.3 木棉花 / 凯悦相关案例
- 产品在使用中因错误快充出现问题
- 公司主动售后、免费更换、加标签、指导正确使用

适合强调：
- 售后负责
- 安全设计
- 质保期内的服务能力

### 8.4 品牌客户案例方向
- 高要求客户看重手感、细节、重量、质感、表面处理
- 这类案例适合支撑“中高端定位”和“专业细节控制”

## 11. 建站内容基础结论

### 11.1 网站最核心的任务
新官网不是为了展示所有产品，而是为了：
- 让客户快速知道我们是谁
- 让客户知道我们擅长什么
- 让客户知道为什么选我们
- 让客户知道哪些产品和项目最适合我们
- 把泛询盘筛成精准询盘

### 11.2 一句话总结
`这个网站应该像一个会筛选客户、提前建立信任、替销售解释核心问题的业务工具。`

## 12. 当前阶段判断

### 12.1 我们现在处于哪个阶段
我们现在已经完成了：
- 基础业务摸底
- 创始人 / 一线业务访谈
- 初步竞品研究
- 公司定位、客户定位、产品定位、卖点定位收敛

我们当前处于：

`第 2 阶段末尾，正在进入第 3 阶段`

更准确地说是：
- `第 2 阶段：业务与市场认知，已经基本完成`
- `第 3 阶段：网站信息架构与页面策略，准备开始`

### 12.2 现在最适合做什么
下一步最适合做的是：
- 首页信息架构
- 产品中心分类方案
- 网站轻量 PRD

不建议现在就直接开始做视觉稿或开发，因为：
- 页面目标和结构还没有最终定稿
- 产品中心分类还需要正式收口
- 每个页面承担什么任务还没完全写清楚
