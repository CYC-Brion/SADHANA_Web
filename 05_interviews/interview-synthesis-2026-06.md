# 访谈综合分析 2026-06

## 1. 访谈对象

**Date**: 2026-06，具体时间未记录  
**Participants**:
- 创始人 / 工厂核心管理者
- 一线业务员 / 外贸销售
- 访谈执行者

**Background**:
- 访谈围绕新官网定位、客户决策、核心产品、核心卖点、询盘质量、案例与素材展开
- 一份更偏工厂与能力视角
- 一份更偏销售与客户成交视角

---

## 2. Current Solution

当前公司对外获客与展示方式主要依赖：
- 国内官网
- 阿里国际站
- 展会
- 老客户与行业沉淀带来的自然信任

当前对外表达存在的问题：
- 口径偏泛，不够聚焦“酒店化妆镜 + 工程定制”
- 网站对销售支持有限
- 客户需要销售反复解释应用场景、材质、结构、交期与信任问题

---

## 3. What They Like About Current Solution

- 公司具备真实工厂和完整五金加工基础，这给高要求客户较强信任感
- 公司在五金结构、个性化工艺、表面处理、定制色方面有明显优势
- 对于高要求客户，公司能够通过多轮打样、深化图确认、样板优化，把设计想法落地
- 销售认为公司在海外工程和品牌客户面前，专业度、品质和响应能力是明显优势
- 现有案例、工厂图、产品图、客户 Logo、部分项目故事和检测资料基本可用于新官网

---

## 4. Problems With Current Solution

- 当前公开定位还不够集中，容易让客户觉得公司是泛五金或泛镜类供应商
- 对外表达没有把“解决结构问题、平衡工艺与成本、支持定制项目”这类核心价值打透
- 客户第一次联系时，对使用场景、材质选择、是否干湿分离、安规要求、交期边界不清楚，销售需要大量解释
- 价格是最常见流失点，尤其面对低价对手、品牌商压价和中东等高价格敏感市场
- 对定制高要求项目来说，交期是另一高风险点，尤其在订单拥挤或复杂定制情况下

---

## 5. Key Insights

### 5.1 公司真正的定位不是“卖镜子”，而是“把设计和项目需求落地”
- 创始人明确更倾向把公司定义为 `定制解决方案供应商`
- 公司的真正优势不是标准化 SKU，而是：
  - 五金结构沉淀
  - 个性化工艺实现能力
  - 把设计师和甲方的要求转成可生产方案
  - 在品质、工艺、成本之间找平衡

### 5.2 网站应聚焦“酒店工程 + 卫浴空间 + 个性化定制”
- 访谈中多次明确：
  - 想要的是更精准询盘，不是更多泛流量
  - 最想吸引的是酒店工程、卫浴空间、化妆台面相关的定制需求
  - 不想吸引塑料镜、低端通货、纯低价比价型需求

### 5.3 真实主力产品线已经比较清楚
- 壁挂折叠镜 / LED 壁挂镜是最重要、最容易带来询盘的产品线
- 台式镜是重要品类，但更适合做精选，而不是全量堆放
- 手柄镜和灯具类更适合作为补充，不建议首版主推
- 代表工厂能力的，不只是标品，而是 `个性化设计师款壁挂镜 / 工艺要求高的酒店挂镜`

### 5.4 客户真正买单的不是“便宜”，而是“解决复杂问题的能力”
- 客户选择公司的核心原因集中在：
  - 结构解决能力
  - 品质与细节控制
  - 表面处理与材质质感
  - 定制能力
  - 售前售中售后的快速配合
- 对高要求客户来说，价格不是第一优先级，质量和细节更重要
- 对低价型客户或品牌商，价格会是关键门槛

### 5.5 公司有非常适合官网讲的差异化故事
- 日本客户案例：
  - 客户 SOP 严格
  - 公司在磨合后快速整改并稳定达标
  - 体现 `快速反应 + 高执行力 + 解决问题能力`
- 德国客户案例：
  - 设计方案不适合直接开模
  - 公司通过五金工艺替代模具方案
  - 帮客户在定制效果和成本之间取得平衡
- 木棉花酒店 / 凯悦相关案例：
  - 产品在使用中因错误快充出现问题
  - 公司主动售后、免费更换、加标签、指导正确使用
  - 体现 `售后负责 + 安全设计 + 长期配合`

### 5.6 销售视角补充了一个很关键的信息
- 有效询盘不是“随便问价格”，而是：
  - 有真实产品需求
  - 有一定行业相关采购经验
  - 能进入具体参数沟通
  - 目标场景明确
- 这意味着官网必须尽量把客户从“泛询盘”筛到“明确场景 + 明确品类 + 明确参数”的阶段

## 6. 定位结论

### 6.1 公司定位
建议定位为：

`专注酒店卫浴空间与化妆台面场景的金属化妆镜定制与工程配套工厂`

英文工作表达建议：

`Custom Hotel Makeup Mirror Manufacturer for Hospitality Projects`

备选表达：

`Hospitality Makeup Mirror Factory with OEM/ODM and Engineering Support`

### 6.2 产品定位
网站首版产品重点建议为：
- LED Wall Mounted Makeup Mirrors
- Folding Wall Mounted Makeup Mirrors
- LED Tabletop Makeup Mirrors
- Selected Non-Lit Tabletop Mirrors
- Hotel Custom Mirrors

弱化：
- 手柄镜
- 灯具类
- 低价通货型产品

### 6.3 客户定位
优先客户：
- 酒店工程客户
- 卫浴空间项目客户
- 设计师主导的定制项目
- 中高端品牌或采购方

非优先客户：
- 单纯低价比价客户
- 与酒店 / 卫浴空间无关的泛镜类买家
- 低端塑料镜或小商品型需求

### 6.4 卖点定位
官网最值得反复强调的 3 个核心卖点：

1. 五金结构与工艺落地能力
2. 高品质材质与表面处理控制
3. OEM / ODM 定制配合与工程项目支持

可作为辅助卖点的内容：
- 真实工厂
- 出口经验
- 安规与材料合规意识
- 售后响应

### 6.5 网站任务定位
新官网最主要不是展示所有产品，而是：

- 建立高信任感
- 解释公司为什么适合做工程与定制
- 把客户从泛询盘引导到精准询盘
- 降低销售重复解释成本
